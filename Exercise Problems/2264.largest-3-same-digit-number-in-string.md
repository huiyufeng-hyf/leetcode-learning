**https://leetcode.cn/problems/largest-3-same-digit-number-in-string/description/**

- Solution by enumeration
```
public class Solution {
    public string LargestGoodInteger(string num) {
        for (var i = 9; i >= 0; i--)
        {
            var tmp = i.ToString() + i.ToString() + i.ToString();
            if (num.IndexOf(tmp) >= 0)
                return tmp;
        }
        return string.Empty;
    }
}
```
**Python**
```
class Solution:
    def largestGoodInteger(self, num: str) -> str:
        for i in range(9, -1, -1):
            tmp = str(i) * 3
            if tmp in num:
                return tmp
        return ""
```

- Recommendation by greedy
```
class Solution:
    def largestGoodInteger(self, num: str) -> str:
        n = len(num)
        res = ""
        for i in range(n - 2):
            if num[i] == num[i+1] == num[i+2]:
                res = max(res, num[i:i+3])
        return res
```
