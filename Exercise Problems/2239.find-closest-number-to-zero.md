**https://leetcode.cn/problems/find-closest-number-to-zero/description/**

- Solution by enumeration with greedy
```
public class Solution {
    public int FindClosestNumber(int[] nums) {
        var closest = nums[0];
        var largest = nums[0];
        foreach (var item in nums)
        {
            if ((Math.Abs(item) < Math.Abs(closest)) || ((Math.Abs(item) == Math.Abs(closest) && item > largest)))
            {
                closest = item;
                largest = item;
            }
        }
        return largest;
    }
}
```

- Recommendation by enumeration
```
class Solution:
    def findClosestNumber(self, nums: List[int]) -> int:
        res = nums[0]
        dis = abs(nums[0])
        for num in nums:
            if abs(num) < dis:
                dis = abs(num)
                res = num
            elif abs(num) == dis:
                res = max(res, num)
        return res
```
